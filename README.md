# Banking Data Intelligence Platform

## Project Overview
A financial transaction analysis project built using Python and Pandas
to explore transaction patterns and identify fraudulent activities.

## Dataset
- Dataset: PaySim Financial Transactions
- Total Transactions: 6,362,620
- Total Columns: 11
- Fraud Transactions: 8,213
- Overall Fraud Rate: 0.1291%

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Key Business Insights
- Fraud transactions were identified in CASH_OUT and TRANSFER.
- Average fraud transaction amount: 1,467,967.30
- Average non-fraud transaction amount: 178,197.04
- Overall fraud rate: 0.1291%

## Project Structure
- data/: Source dataset
- notebooks/: Jupyter Notebook analysis
- outputs/charts/: Saved visualizations
- outputs/reports/: Generated reports

## Project Status
Python-based exploratory data analysis completed.
